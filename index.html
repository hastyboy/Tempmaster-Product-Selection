1) Input Schedule (Compact Line Codes)

Paste one unit per line using pipe-delimited tokens. No spaces required. Stable, computer-first schema:

TAG | FAMILY | SIZECODE | HEATTYPE | HEATCAP | VOLT | DRIVE | FILTER | DUCT
Example: 
RTU-1|KT|120|E|18|4|3|M13|B
RTU-2|KB|078|S|180|2|2|STD|B
Token meanings:
  • FAMILY: KJ / KT / WP / KB
  • SIZECODE: 037,049,061,078,090,102,120,150
  • HEATTYPE: C (cool only) / E (electric) / N (gas Al) / S (gas SS)
  • HEATCAP: if E = kW (ex 18). if N/S = MBH (ex 180)
  • VOLT: 2 (208/230-3-60) / 4 (460-3-60) / 5 (575-3-60)
  • DRIVE: 2 standard / 3 high static
  • FILTER: STD / M8 / M13 (or leave blank)
  • DUCT: B bottom / S side (or leave blank)
